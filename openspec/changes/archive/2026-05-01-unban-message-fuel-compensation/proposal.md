# 提案：管理员解封时发送解封消息并补偿燃素

变更名称：`unban-message-fuel-compensation`

目的（What）:
- 当管理员选择解封被封禁的用户时，系统应向被解封用户发送一条标准化的解封消息，并自动发放燃素补偿。
- 默认补偿文案为：
  > 由于反作弊系统将您误封，在此，ChemistryUNO开发组向受到影响的研究员提供100燃素补偿，感谢研究员对维护纯净游戏环境做出的贡献

原因（Why）:
- 改善用户体验：对于误封的研究员，主动发送说明并发放补偿能降低用户抱怨并提升信任。
- 合规与审计：在解封流程中记录补偿行为，便于运营与法律审计。
- 自动化与一致性：把文案与补偿逻辑从人工操作中抽离，降低人为错误。

范围：
- 后端：解封接口/管理员控制台调用处（handlers/appeal.go 或 backend/anticheat/appeal.go）添加消息发送与燃素发放逻辑。
- 配置：新增可配置的默认补偿数值与默认文案（放在 `config/anticheat.yaml` 或统一配置位置）。
- 审计：在现有的解封记录中增加补偿字段与日志条目（无需新 DB 表，优先使用现有审计记录扩展）。
- 测试：单元测试与集成测试覆盖发放逻辑与错误回滚（保证在发放失败时回滚解封或记录补偿失败状态）。

风险与回退：
- 若发放燃素失败，应保证不会重复发放；失败时需记录补偿失败并通知运营人工处理。可在最初阶段使用标记（补偿状态：pending/ok/failed）。
