# 《化学 UNO》研究员服务协议 (User Agreement)

欢迎来到《化学UNO》实验基地（以下简称“本系统”）。在您正式启用研究员身份并参与实验（即使用本服务）之前，请务必仔细阅读并理解本《研究员服务协议》（以下简称“本协议”）。

**一旦您进入本系统或点击确认，即表示您已阅读、理解并同意接受本协议的所有条款。**

## 1. 账号与身份
1.1 **研究员编号 (UID)**：系统将为您分配唯一的 UID。该编号是您在实验基地唯一的身份标识。
1.2 **安全义务**：您负责维护账号及密码的安全。建议启用系统提供的 **2FA (双重身份验证)** 或 **WebAuthn (生物识别)** 以确保实验数据的安全性。
1.3 **禁止转让**：研究员身份严禁出租、借用、转让或售卖。

## 2. 实验物资：燃素 (Phlogiston)
2.1 **定义**：燃素是本系统内的虚拟研究资源，仅限用于系统内的功能兑换或实验参与。
2.2 **属性**：燃素不具有任何法币属性，也不具备实际经济价值，严禁进行任何形式的线下现金交易。
2.3 **管理**：系统有权根据实验平衡性调整燃素的获取速率与消耗规则。

## 3. 插件系统协议
3.1 **第三方贡献**：本系统支持由第三方开发者提供的插件。您理解并同意，使用非官方插件可能存在实验不稳定性风险。
3.2 **代码执行**：启用第三方插件即视为您授权其在您的浏览器环境下执行特定的功能逻辑。
3.3 **合规性**：研究员不得利用插件系统开发任何具有攻击性、破坏性或窃取他人隐私的功能。

## 4. 行为准则
4.1 **实验规范**：禁止使用任何自动化脚本 (Bots)、作弊软件或利用系统漏洞干扰实验公平性。
4.2 **沟通规范**：在实验内通信线程中，请保持文明沟通。禁止发布辱骂、违法、违规或误导性信息。
