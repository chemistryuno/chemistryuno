# 新手指引系统 - 无遮罩高亮优化

## 🎯 优化内容

### 1. 移除背景遮罩，保持原始亮度
**问题**：之前使用 `bg-black/80` 遮罩层降低了整个页面的亮度

**解决方案**：完全移除遮罩层和镂空阴影，只通过边框高亮引导用户注意

#### 代码对比
```vue
<!-- ❌ 旧版本 - 整个页面变暗 -->
<div class="bg-black/80"></div>
<div style="box-shadow: 0 0 0 9999px rgba(0, 0, 0, 0.8);"></div>

<!-- ✅ 新版本 - 背景保持原始亮度 -->
<!-- 无遮罩层 -->
```

#### 视觉效果
- ✅ **背景保持原始亮度** - 页面不变暗
- ✅ **聚光灯边框增强** - 80% 不透明度的 cyan-400 边框
- ✅ **发光效果增强** - 60% 不透明度的外发光
- ✅ **保留所有动画** - 扫描线、角落装饰、脉冲效果

### 2. 增强聚光灯边框可见度
为了在无遮罩的情况下保持高亮效果的清晰度：

```vue
<!-- 边框透明度提升 60% → 80% -->
<div class="border-4 border-cyan-400/80 animate-pulse-slow"></div>

<!-- 发光效果增强 40% → 60% -->
<div class="shadow-[0_0_60px_20px_rgba(34,211,238,0.6)]"></div>
```

### 3. 增强提示卡片对比度
确保提示卡片在亮色背景下清晰可见：

```vue
<!-- 更强的阴影和外边框 -->
<div class="
  shadow-[0_20px_60px_-15px_rgba(0,0,0,0.8)]
  border-2 border-cyan-400/40
  ring-4 ring-black/20
"></div>
```

#### 卡片优化细节
- **阴影**：从 `shadow-2xl` 升级到自定义深阴影
- **边框**：从 1px 升级到 2px，透明度 30% → 40%
- **外环**：新增 4px 黑色外环，增强边界感

### 4. 移动端导航指引智能适配
根据屏幕尺寸动态选择目标元素

## 📐 技术实现

### 层级关系（无遮罩版本）
```
z-index: 9999 (tutorial-overlay)
├── 聚光灯区域
│   ├── 发光边框 (border-cyan-400/80)
│   ├── 外发光效果 (shadow rgba(34,211,238,0.6))

│   └── 四角装饰

    ├── 2px 边框
    └── 4px 外环
```

- **边框宽度**：4px
- **边框颜色**：cyan-400 (80% 不透明度)
- **发光半径**：60px
- **发光扩散**：20px
- **发光颜色**：rgba(34,211,238,0.6)
