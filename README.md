# 化学 UNO (Chemistry UNO)

一个基于化学反应逻辑的策略卡牌游戏，在经典 UNO 的玩法基础上融入了科学严谨的化学合成逻辑。

## 🧪 游戏核心逻辑

在化学 UNO 中，出的每一张牌都必须符合化学规律。

1. **反应合成**：你手上的卡牌（元素卡）不能直接叠加，而是必须能与桌面当前的**物质**发生化学反应。
2. **反应数据库**：系统内置了一套涵盖初高中及部分大学基础化学的反应方程式库。系统会自动通过该数据库计算你手牌中所有符合逻辑的合成方案。
3. **动态桌面**：当你成功出牌并反应后，桌面的物质会更新为你合成后的产物（如：当前桌面是 $O_2$，你打出 $H$ 元素卡，桌面物质将变为 $H_2O$）。

## 🃏 卡牌种类

### 元素卡

包含 $H, O, C, S, Na, Mg, Al, Fe, Cu$ 等多种常见化学元素。

### 功能牌 (功能模拟)

* **惰性气体 ($He / Ne / Ar / Kr$)**：作为稀有气体，它们不参与普通反应。打出时会使目前的实验方向进行**反转**。
* **金 ($Au$)**：由于其极不活泼的化学性质，被视为“万能催化剂”。打出后将**跳过**下一位玩家，且其后的玩家开启“任意反应模式”（可不受限制出牌一次）。

## ⚙️ 核心机制

* **实验时限**：每个回合限时 **30 秒**。若超时未行动，系统将强制摸牌并跳过。
* **防僵局系统**：如果连续 3 个回合无人出牌，实验室会触发“化学动力学补偿”，强制开启一轮任意反应模式以打破僵局。
* **实验存档**：使用 Base64 序列化逻辑与校验码技术，支持将当前实验状态导出为还原代码，方便随时复现历史对局。

## 🚀 快速开始

本项目为纯前端实现，无需任何后端环境。

1. 克隆或下载本仓库。
2. 直接双击 `index.html` 即可在浏览器中开启您的化学之旅。

## 🛠️ 技术栈

* **HTML5 / CSS3**: 构建实验室 UI 与卡牌动画。
* **Vanilla JavaScript**: 编写化学反应引擎及 AI 决策逻辑。
