# 《化学 UNO》隐私政策 (Privacy Policy)

**生效日期：2026年3月14日**

本《隐私政策》旨在解释《化学UNO》实验基地（以下简称“本基地”、“我们”或“本系统”）如何收集、使用、存储及保护您的个人信息。保护研究员的隐私是我们最高优先级任务。

## 1. 收集的信息
1.1 **基本账户信息**：包括但不限于您的用户名、电子邮箱地址、UID（研究员编号）、头像及账户设置。
1.2 **设备与日志信息**：为优化实验环境，我们可能自动收集 IP 地址、浏览器类型、操作系统版本、访问时间及特定的实验行为日志（如发牌、合成反应）。
1.3 **安全认证数据**：如果您启用了 2FA (双重身份验证) 或 WebAuthn (生物识别)，我们将存储加密后的凭证及同步密钥，但不收集原始指纹或面部识别详细信息。
1.4 **三方统计数据**：本系统集成 **Microsoft Clarity** 及 **Google Analytics**（视环境变量配置而定），用于分析用户行为及界面交互热点，以改进研究体验。

## 2. 使用目的
2.1 **维持实验运行**：处理游戏匹配、排行（Ranking System）、燃素（Phlogiston）发放及等级系统（Level System）。
2.2 **通信功能**：支持实验内聊天线程及反馈机制（Feedback System）。
2.3 **账户安全**：防止未经授权的访问及反作弊系统监控（Anti-Cheat Mechanism）。
2.4 **系统优化**：分析实验故障及性能瓶颈，更新实验方案（Deck Configs）。

## 3. 数据共享与披露
3.1 **插件隔离**：当您启用第三方插件时，插件可能会读取您的实验状态。我们通过沙箱环境最小化隐私泄露风险，但建议仅安装信誉良好的插件。
3.2 **管理员权限**：为维护公平性，基地管理员有权在必要时查看违规玩家的实验日志及 UID 历史。
3.3 **法律要求**：除法律法规另有规定外，未经您的同意，我们不会将您的信息提供给任何第三方商业机构。

## 4. 数据存储与安全
4.1 **存储期限**：您的信息将仅保留至本实验活跃期间。如账号注销，相关个人数据将被永久抹除或匿名化处理。
4.2 **技术防护**：我们使用主流的加密通信协议 (SSL/TLS) 保护数据传输。数据库采用 AES-256 加密存储敏感字段。

## 5. 您的权利
5.1 **访问与更正**：您可以在个人配置页面（Profile Page）随时更新您的昵称、头像及安全设置。
5.2 **账户注销**：您有权通过反馈渠道申请永久注销研究员身份及抹除全部关联数据。
5.3 **知情权**：本基地若发生数据迁移、协议更新或重大维护，将通过全局公告系统（Announcement System）通知所有研究员。

## 6. 联系我们
如有关于隐私保护或数据安全的疑问，请通过 [反馈系统 (Feedback)] 或我们的开发者通道与“首席研究员”直接对话。
